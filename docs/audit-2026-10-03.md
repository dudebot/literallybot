pre-existing working-copy edits are outside this change.

  modules. Missing docstrings fall back to the name/state. Discord UI not run live.

  The redundant remove op is retired. Existing panel services are reused.

  output is silent, with an info log. Ordinary empty output keeps its error path.

  requests explicitly distinguish metadata from pixels. Qwen3.5 4b capability was

  LLMClient answered “Blue square” correctly. Existing stored catalogs are not
  rewritten; set vision:true for a verified configured model.

  through its established library surface; search returns links; channel migration
  paths are internal exports. The raw attachment ADMIN gate remains intact. Do not
  introduce an artifact registry or widen permissions without an actual consumer.

  primitive, now with a reactor cursor. Missing guild-wide membership pagination

  Historical voice/activity retention is separate and remains unimplemented.

## Documentation and test validity (#91/#62)

Useful existing tests protect actor history privacy, configuration durability,
registry permissions, role conflict preservation and model history cache behavior.
New retained scenarios protect precedence-preserving edits, bot-only reaction
cleanup, image transport/cap, guild budget scope, EOS silence, and history cursor
propagation. They use real temporary Config and mock external I/O. The EOS test
executes the public reply pipeline; the vision check uses a real local provider.

Danbooru remains a cog leaf with one headless service shared by listener and op.
Threaded HTTP calls have bounded timeouts, encoded query parameters and Basic
credentials outside URLs. Response shape/errors and actual returned ratings are
validated before selecting an image; safe mode means the provider's general
rating. Neutral mocked responses exercise those boundaries; no live API claim.

Generic follow-up fixes keep related user values atomic and preserve provider
usage counters across pricing-extractor versions. Save scheduling releases the
data lock before taking the save lock. Neutral regressions cover these behaviors,
actual bot cog registration/removal, legacy role storage and emoji identity, and
admin scope. The final integrated suite passes 76 tests with the newer dependency
environment; no private product fixtures or behavior were introduced.

No bot restart, message send, deployment, remote push or issue closure was part of
this audit. Local model validation sent only a synthetic geometric image.
